No other device with the new version yet? Type the address and key instead

On the computer where BballData is connected to your Sheet, open Settings → Google Sheet → Change key or address…. Copy the address from the box and paste it in the first field. Then press Copy script there and paste it in the second field — only the key is taken from it. Close that window without pressing anything else.

Also found in your Google Sheet: Extensions → Apps Script (the line const ACCESS_KEY = '…') and Deploy → Manage deployments (the Web app URL).

Cancel

Never use Connect a Google Sheet… → Copy script on a second device: it makes a new key, and your other devices would stop syncing.
