# BballData — online app

Open **https://6y6o4ka.github.io/bballdata-app/** on a phone, tablet or computer.
To give a new device the same data, open **https://6y6o4ka.github.io/bballdata-app/connect.html** on a device that is already connected and scan the code.

This repository holds only the finished app files, generated from a private repository. It never holds players or any other personal data: those live on each device and in the coach's own Google Sheet.

- `index.html` — the app
- `connect.html` — connects a device to the coach's Google Sheet
- `sw.js`, `manifest.webmanifest`, icons — offline mode and "Add to Home screen"
- `qrcode.js` — QR code generator by Kazuhiko Arase, MIT licence (`qrcode-LICENSE.txt`)
